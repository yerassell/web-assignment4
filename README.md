# web-assignment4

https://yerassell.github.io/web-assignment4/

This repository includes three parts of tasks completed. Each html file has a navigation bar that links to each others.

## Brief description
- index.html contains the Contact Form using simple commands in html and css. 
- part2.html contains the Contact From using Bootstrap and JS, including validations.
- part3.html is a Registration Form using Bootstrap and JS, including validations.

## Instructions
To run the project:
1. Clone this repository to your local device (if Git is downloaded in your device)
   ```bash
   https://github.com/yerassell/web-assignment4.git
   ```
   If Git is not downloaded in your device, click the green button **Code** ath the right top of the repository, select **download ZIP**, unzip the downloaded file.
2. Open the project folder in your device
3. Open the html file inside any task folder. It will open and display the website on your default web browser. The navigation bar will guide you to other tasks.
